## Часть 1. Математика без циклов (для задач с большими числами до $10^9$)

### 1. Ввод данных
* Число на отдельной строке:
  ```python
  a = int(input())
```
* Несколько чисел в одной строке через пробел:
  ```python
  a, b = map(int, input().split())
```

### 2. Деление нацело и остаток
* `//` — деление нацело (отбрасывает дробную часть): `17 // 5` дает `3`.
* `%` — остаток от деления: `17 % 5` дает `2`.

**Как разбрать число на цифры (на примере трехзначного `n = 385`):**
* Последняя цифра (единицы): `n % 10` $\rightarrow$ `5`
* Первая цифра (сотни): `n // 100` $\rightarrow$ `3`
* Средняя цифра (десятки): `(n // 10) % 10` $\rightarrow$ `8`

### 3. Округление вверх (Формула)
Чтобы разделить $n$ на $k$ с округлением вверх без использования условий `if`:
$$\text{Результат} = (n + k - 1) // k$$

### 4. Минимум и максимум
Вместо громоздких условий используйте встроенные функции:
* `max(a, b, c)` — находит наибольшее число.
* `min(a, b, c)` — находит наименьшее число.

## Часть 2. Логика и условия (`if`, `and`, `or`, `not`)

```python
x = int(input())
if x > 0 and x % 2 == 0:
    print("Положительное и чётное")
elif x == 0:
    print("Ноль")
else:
    print("Отрицательное или нечётное")
```

* **`and` (И)** — истина, если оба условия верны.
* **`or` (ИЛИ)** — истина, если верно хотя бы одно условие.
* **`not` (НЕ)** — инвертирует значение.
* **Приоритет:** Операция `and` выполняется раньше, чем `or`. Для изменения порядка используйте скобки `()`.

## Часть 3. Перебор и циклы `for`

Цикл `for` позволяет повторить действие или перебрать диапазон чисел:
* `range(5)` перебирает числа от `0` до `4`.
* `range(1000, 10000)` перебирает все четырехзначные числа (для задачи №1).

**Пример вывода в одну строку:**
```python
for i in range(5):
    print(i, end="")  # Выведет: 01234
```

**Вложенные циклы (для таблиц и стен):**
```python
n, m = 3, 5
for i in range(n):
    for j in range(m):
        print("1", end="")
    print()  # Переход на новую строку после каждого ряда
```

## Часть 4. Работа со строками

В Python число можно превратить в строку через `str(x)` и обращаться к его цифрам по индексам (нумерация с нуля!):

```python
x = 4815
s = str(x)
# s[0] -> '4'
# s[1] -> '8'

# Проверить наличие цифры:
if "8" in s:
  print("Есть восьмёрка!")

# Сумма цифр:
summa = int(s[0]) + int(s[1]) + int(s[2]) + int(s[3])
```

**Циклический шаблон (для раскраски стен):**
Чтобы повторять паттерн (например, `"112233"`) по кругу, используйте остаток от деления на длину шаблона:
```python
pattern = "112233"
m = 10
for j in range(m):
    print(pattern[j % 6], end="")
```
