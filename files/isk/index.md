# Шпаргалка по олимпиадному программированию (ВсОШ, 7–8 классы)

Эта теория разбита на блоки, которые помогут решать задачи без сложных циклов (там, где нужны быстрые математические формулы) и с помощью простых циклов и строк (для перебора и работы с матрицами).

## Часть 1. Математика без циклов (для задач с большими числами до $10^9$)

### 1. Ввод данных

Если каждое число дается на отдельной строке:

```python
a = int(input())
b = int(input())
```

Если несколько чисел записаны в одной строке через пробел:

```python
a, b = map(int, input().split())
```

---

### 2. Деление нацело и остаток от деления

В школьном курсе математики знак деления с остатком записывается иначе, но в языке Python для этого служат два оператора:

* `//` — деление нацело (целая часть от деления, отбрасывает дробную часть):
  * `17 // 5` дает `3`
* `оператор остатка` — дает остаток от деления:
  * `17 остаток от 5` дает `2` (так как $17 = 3 \times 5 + 2$)

**Как разобрать трехзначное число `n = 385` на отдельные цифры:**

* **Последняя цифра (единицы):** берем остаток от деления на 10
  * `n % 10` дает `5`
* **Первая цифра (сотни):** делим нацело на 100
  * `n // 100` дает `3`
* **Средняя цифра (десятки):** сначала убираем последнюю цифру (`n // 10` дает `38`), затем берем от нее остаток при делении на 10
  * `(n // 10) % 10` дает `8`

---

### 3. Округление вверх (Формула без условий)

Обычное деление нацело `n // k` всегда округляет результат вниз. 
Если требуется разделить $n$ предметов по $k$ мест в коробке так, чтобы упаковать абсолютно все предметы (то есть округлить вверх), используется универсальная олимпиадная формула:

$$
\text{Количество коробок} = (n + k - 1) // k
$$

**Проверка формулы при вместимости коробки $k = 5$:**
* Для $n = 10$: $(10 + 5 - 1) // 5 = 14 // 5 = 2$ (ровно две коробки).
* Для $n = 11$: $(11 + 5 - 1) // 5 = 15 // 5 = 3$ (потребуется третья коробка).

---

### 4. Минимум и максимум

Вместо длинных цепочек проверок `if` в Python используются встроенные функции:

* `max(a, b, c)` — мгновенно возвращает самое большое число.
* `min(a, b, c)` — мгновенно возвращает самое маленькое число.

## Часть 2. Логика и условия (`if`, `and`, `or`, `not`)

Конструкция ветвления позволяет программе принимать решения:

```python
x = int(input())

if x > 0 and x % 2 == 0:
    print("Положительное и чётное")
elif x == 0:
    print("Ноль")
else:
    print("Отрицательное или нечётное")
```

**Логические связки:**
* **`and` (И)** — истинно только тогда, когда выполняются оба условия одновременно.
* **`or` (ИЛИ)** — истинно, если выполняется хотя бы одно из условий (или оба сразу).
* **`not` (НЕ)** — меняет логическое значение на противоположное.

**Приоритет операций:**
Операция `and` логически равносильна умножению, а `or` — сложению. Поэтому `and` всегда выполняется раньше, чем `or`. Если нужно изменить порядок вычислений, обязательно используйте круглые скобки `()`.

## Часть 3. Простые циклы `for` и вывод данных

Цикл `for` применяется, когда нужно повторить действие заданное число раз или перебрать подряд диапазон чисел:

* `range(5)` перебирает значения от `0` до `4` включительно (всего 5 шагов).
* `range(1000, 10000)` перебирает все четырехзначные числа от `1000` до `9999`.

**Вывод нескольких значений в одну строку без пробелов:**

```python
for i in range(5):
    print(i, end="")
# Результат вывода: 01234
```

**Вложенные циклы (для построения таблиц, сеток и кирпичных стен):**

```python
n = 3  # Количество строк
m = 5  # Количество символов в строке

for i in range(n):
    for j in range(m):
        print("1", end="")
    print()  # Пустой print без параметров выполняет переход на следующую строку
```

## Часть 4. Работа со строками

Превратив целое число в строку командой `str(x)`, можно легко обращаться к любой его цифре по порядковому номеру (индексу). Нумерация символов в строке всегда начинается с **0**:

```python
x = 4815
s = str(x)

# s[0] -> символ '4'
# s[1] -> символ '8'
# s[2] -> символ '1'
# s[3] -> символ '5'

# Проверка наличия конкретной цифры в числе:
if "8" in s:
    print("В числе присутствует цифра 8")

# Вычисление суммы цифр через обратное преобразование в числа:
summa = int(s[0]) + int(s[1]) + int(s[2]) + int(s[3])
```

**Построение периодических шаблонов (для раскраски рядов):**

Если нужно многократно повторять шаблон по кругу (например, повторяющуюся цепочку цветов `"112233"`), номер текущего символа берется по остатку от длины шаблона:

```python
pattern = "112233"
m = 10

for j in range(m):
    # Номер позиции зацикливается в диапазоне от 0 до 5
    index = j % 6
    print(pattern[index], end="")

# Результат вывода: 1122331122
```
