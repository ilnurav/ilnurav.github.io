## 1. Арифметика и линейные алгоритмы
*Работа с вводом/выводом, целочисленным делением (`//`), остатком от деления (`%`) и вещественными числами.*

1. **Дано натуральное число. Выведите его последнюю цифру.**
   ```python
   n = int(input("Введите натуральное число: "))
   print("Последняя цифра:", n % 10)
   ```

2. **Длина Московской кольцевой автомобильной дороги — 109 километров. Байкер Вася стартует с нулевого километра МКАД и едет со скоростью $v$ километров в час. На какой отметке он остановится через $t$ часов?**
   ```python
   v = int(input("Скорость v (км/ч): "))
   t = int(input("Время t (ч): "))
   print("Отметка на МКАД:", (v * t) % 109)
   ```

3. **Дано положительное действительное число $X$. Выведите его дробную часть.**
   ```python
   x = float(input("Введите число X: "))
   fractional_part = x - int(x)
   print("Дробная часть:", round(fractional_part, 10))
   ```

4. **За день машина проезжает $n$ километров. Сколько дней нужно, чтобы проехать маршрут длиной $m$ километров? Программа получает на вход числа $n$ и $m$.**
   ```python
   n = int(input("Км в день (n): "))
   m = int(input("Длина маршрута (m): "))

   # Округление вверх без библиотеки math:
   days = (m + n - 1) // n
   print("Необходимо дней:", days)
   ```

5. **Пирожок в столовой стоит $a$ рублей и $b$ копеек. Определите, сколько рублей и копеек нужно заплатить за $n$ пирожков. Программа получает на вход три числа: $a$, $b$, $n$, и должна вывести два числа: стоимость покупки в рублях и копейках.**
   ```python
   a = int(input("Рубли (a): "))
   b = int(input("Копейки (b): "))
   n = int(input("Количество (n): "))

   total_kopecks = (a * 100 + b) * n
   rubles = total_kopecks // 100
   kopecks = total_kopecks % 100

   print("Рублей:", rubles, "Копеек:", kopecks)
   ```

6. **Даны значения двух моментов времени, принадлежащих одним и тем же суткам: часы, минуты и секунды для каждого из моментов времени. Известно, что второй момент времени наступил не раньше первого. Определите, сколько секунд прошло между двумя моментами времени.**
   ```python
   h1 = int(input("Часы 1: "))
   m1 = int(input("Минуты 1: "))
   s1 = int(input("Секунды 1: "))

   h2 = int(input("Часы 2: "))
   m2 = int(input("Минуты 2: "))
   s2 = int(input("Секунды 2: "))

   sec1 = h1 * 3600 + m1 * 60 + s1
   sec2 = h2 * 3600 + m2 * 60 + s2

   print("Прошло секунд:", sec2 - sec1)
   ```

7. **Дано трехзначное число. Найдите сумму его цифр.**
   ```python
   n = int(input("Введите трехзначное число: "))

   d1 = n // 100
   d2 = (n // 10) % 10
   d3 = n % 10

   print("Сумма цифр:", d1 + d2 + d3)
   ```

### 2.3 Перебор чисел с условиями

9. **Вывести на экран числа от `1000` до `9999` такие, что все цифры различны.**
   ```python
   for num in range(1000, 10000):
       s = str(num)
       if s[0] != s[1] and s[0] != s[2] and s[0] != s[3] and \
          s[1] != s[2] and s[1] != s[3] and s[2] != s[3]:
           print(num, end=" ")
   print()
   ```

10. **Вывести на экран числа от `1000` до `9999` такие, что среди цифр нет цифр `5` и `6`.**
    ```python
    for num in range(1000, 10000):
        s = str(num)
        if "5" not in s and "6" not in s:
            print(num, end=" ")
    print()
    ```

11. **Вывести все пятизначные числа, которые делятся на `2`, у которых средняя цифра нечетная, и сумма всех цифр делится на `4`.**
    ```python
    for num in range(10000, 100000):
        if num % 2 == 0:
            s = str(num)
            mid = int(s[2])
            digits_sum = int(s[0]) + int(s[1]) + int(s[2]) + int(s[3]) + int(s[4])
            if mid % 2 != 0 and digits_sum % 4 == 0:
                print(num, end=" ")
    print()
    ```

12. **Вывести на экран числа от `1000` до `9999` такие, что среди цифр есть цифра `3`.**
    ```python
    for num in range(1000, 10000):
        if "3" in str(num):
            print(num, end=" ")
    print()
    ```

13. **Найдите трехзначные числа, равные сумме кубов своих цифр.**
    ```python
    for num in range(100, 1000):
        d1 = num // 100
        d2 = (num // 10) % 10
        d3 = num % 10
        if (d1**3 + d2**3 + d3**3) == num:
            print("Число Армстронга:", num)
    ```

14. **Сколько существует четырехзначных чисел, которые в 600 раз больше суммы своих цифр?**
    ```python
    count = 0
    for num in range(1000, 10000):
        d1 = num // 1000
        d2 = (num // 100) % 10
        d3 = (num // 10) % 10
        d4 = num % 10
        digits_sum = d1 + d2 + d3 + d4

        if num == 600 * digits_sum:
            count += 1
            print("Найдено число:", num)

    print("Всего таких чисел:", count)
    ```

## 3. Строки и обработка текста

1. **В заданном предложении найти пару слов, из которых одно является обращением другого.**
   ```python
   sentence = input("Введите предложение: ")
   words = sentence.split()

   # Очищаем слова от знаков препинания
   clean_words = []
   for w in words:
       clean_words.append(w.strip(".,!?;:").lower())

   # Ищем пары
   for i in range(len(clean_words)):
       for j in range(i + 1, len(clean_words)):
           word1 = clean_words[i]
           word2 = clean_words[j]
           if word1 == word2[::-1]:
               print("Пара:", word1, "и", word2)
   ```

2. **Дан email в строке. Определить, является ли он корректным (наличие символа `@` и точки, наличие не менее двух символов после последней точки и т.д.).**
   ```python
   email = input("Введите email: ").strip()

   if "@" in email and "." in email:
       parts = email.split("@")
       # Проверяем, что ровно один символ @ и домена не пуста
       if len(parts) == 2 and parts[0] != "" and "." in parts[1]:
           domain_parts = parts[1].split(".")
           # Проверяем, что после последней точки хотя бы 2 символа
           if len(domain_parts[-1]) >= 2:
               print("Email корректен")
           else:
               print("Email некорректен")
       else:
           print("Email некорректен")
   else:
       print("Email некорректен")
   ```

3. **Дана строка. Определите, является ли она действительным числом.**
   ```python
   s = input("Введите строку: ").strip()

   try:
       val = float(s)
       print("Это действительное число")
   except ValueError:
       print("Это НЕ действительное число")
   ```

4. **Удалите в строке все символы `"!"`.**
   ```python
   s = input("Введите строку: ")
   result = s.replace("!", "")
   print("Результат:", result)
   ```

5. **Дана строка, содержащая полное имя файла (например, `'c:\WebServers\home\testsite\www\myfile.txt'`). Выделите из этой строки имя файла без расширения.**
   ```python
   path = r"c:\WebServers\home\testsite\www\myfile.txt"

   # Заменяем обратные слэши на прямые и разделяем по '/'
   filename = path.replace("\\", "/").split("/")[-1]  # myfile.txt

   # Отделяем название от расширения
   name_only = filename.split(".")[0]                  # myfile

   print("Имя файла без расширения:", name_only)
   ```

6. **Дан текст. Заменить все цифры соответствующими словами.**
   ```python
   digits_words = ["ноль", "один", "два", "три", "четыре", "пять", "шесть", "семь", "восемь", "девять"]

   text = input("Введите текст: ")
   result = ""

   for char in text:
       if char.isdigit():
           result += digits_words[int(char)] + " "
       else:
           result += char

   print("Результат:", result)
   ```

7. **Дано натуральное число. Получить строку, в которой тройки цифр этого числа разделены пробелом, начиная с правого конца (например, `1234567` $\rightarrow$ `1 234 567`).**
   ```python
   n = int(input("Введите число: "))

   # Форматирование с разделением тысяч встроенными средствами Python
   result = f"{n:,}".replace(",", " ")
   print("Результат:", result)
   ```

## 4. Массивы (списки)

### 4.1 Изменение элементов массива

1. **В массиве заменить все числа, большие данного числа, на среднее арифметическое всех чисел массива.**
   ```python
   arr = [10, 25, 5, 40, 15]
   x = 20

   avg = sum(arr) / len(arr)

   for i in range(len(arr)):
       if arr[i] > x:
           arr[i] = avg

   print("Среднее арифметическое:", avg)
   print("Измененный массив:", arr)
   ```

2. **Дан массив. Заменить все числа, меньшие последнего элемента массива, на первый элемент.**
   ```python
   arr = [12, 5, 20, 3, 10]
   first = arr[0]
   last = arr[-1]

   for i in range(len(arr)):
       if arr[i] < last:
           arr[i] = first

   print("Измененный массив:", arr)
   ```

3. **Поменять местами наибольший и наименьший элементы массива.**
   ```python
   arr = [10, 3, 45, 2, 18]

   min_idx = arr.index(min(arr))
   max_idx = arr.index(max(arr))

   # Меняем местами элементы по индексам
   arr[min_idx], arr[max_idx] = arr[max_idx], arr[min_idx]

   print("Результат:", arr)
   ```

### 4.2 Поиск, условия и агрегация

4. **Определить, содержит ли массив данное число $x$.**
   ```python
   arr = [4, 8, 15, 16, 23, 42]
   x = int(input("Введите x: "))

   if x in arr:
       print("Число присутствует в массиве")
   else:
       print("Число отсутствует")
   ```

5. **Найти количество четных чисел в массиве.**
   ```python
   arr = [1, 2, 3, 4, 5, 6, 7, 8]

   count = 0
   for num in arr:
       if num % 2 == 0:
           count += 1

   print("Количество четных чисел:", count)
   ```

6. **Найти количество чисел в массиве, которые делятся на `3`, но не делятся на `7`.**
   ```python
   arr = [3, 21, 9, 14, 12, 42, 15]

   count = 0
   for num in arr:
       if num % 3 == 0 and num % 7 != 0:
           count += 1

   print("Количество элементов:", count)
   ```

7. **Определите, каких чисел в массиве больше: которые делятся на первый элемент массива или которые делятся на последний элемент массива.**
   ```python
   arr = [2, 4, 5, 6, 8, 10, 3]
   first = arr[0]
   last = arr[-1]

   count_first = 0
   count_last = 0

   for num in arr:
       if num % first == 0:
           count_first += 1
       if num % last == 0:
           count_last += 1

   if count_first > count_last:
       print("Больше чисел, делящихся на первый элемент")
   elif count_last > count_first:
       print("Больше чисел, делящихся на последний элемент")
   else:
       print("Количество одинаковое")
   ```

8. **Найдите сумму и произведение элементов массива.**
   ```python
   arr = [1, 2, 3, 4, 5]

   total_sum = sum(arr)

   product = 1
   for num in arr:
       product *= num

   print("Сумма:", total_sum)
   print("Произведение:", product)
   ```

9. **Найдите сумму четных чисел массива.**
   ```python
   arr = [1, 2, 3, 4, 5, 6, 7, 8]

   even_sum = 0
   for num in arr:
       if num % 2 == 0:
           even_sum += num

   print("Сумма четных чисел:", even_sum)
   ```
